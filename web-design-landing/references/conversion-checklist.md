# Conversion Checklist

Use this as a final pass.

## First Impression (0-5 seconds)
- [ ] Value proposition obvious
- [ ] Target audience implied
- [ ] Primary CTA visible
- [ ] No "what is this?" confusion

## Clarity
- [ ] H1 benefit-focused
- [ ] Benefits > features
- [ ] Scannable with bullets
- [ ] Jargon removed

## Action
- [ ] Only one primary CTA
- [ ] CTA copy action-oriented
- [ ] CTA stands out
- [ ] Repeated at end

## Trust
- [ ] Some form of proof present
- [ ] No exaggerated claims
- [ ] Clear offer

## Technical/UX
- [ ] Mobile looks good
- [ ] No horizontal scroll
- [ ] Forms minimal
- [ ] Fast to scan
- [ ] Accessible basics covered

## Verdict
If >= 80% checked -> **Good**. Fix Criticals first regardless of score.
