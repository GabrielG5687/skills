# Landing Page Anatomy

A typical high-converting landing page follows this order. Not every section is mandatory, but order matters.

## Core Sections

| Section | Goal | Notes |
| --- | --- | --- |
| **Above the fold (Hero)** | Grab attention, state value | H1 + subheading + primary CTA. Must work without scroll. |
| **Problem/Agitate** | Show user pain | Speak their language, not your product features. |
| **Solution/Benefits** | Show how you solve it | Focus on outcomes/benefits, not "features list". |
| **Social Proof** | Build trust | Logos, testimonials, numbers, press, or user avatars. |
| **Features/How it works** | Clarify without overload | 3-4 key points max. Use icons sparingly. |
| **Objections/FAQ** | Remove doubt | Answer pricing, "is this for me?", setup, etc. |
| **Final CTA** | Drive action again | Repeat the same primary action with minimal copy. |
| **Footer** | Minimal navigation/legal | Avoid adding new CTAs here. |

## Rules

- **One goal**: Pick ONE primary action and reinforce it.
- **Benefit-first**: "Save 2 hours/week" > "Automated reports".
- **Scan-friendly**: Use headings, bullets, short paragraphs.
- **Progressive**: Reveal info as needed, don't dump everything at top.
