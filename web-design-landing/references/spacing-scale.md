# Spacing Scale (8pt Grid)

Stick to multiples of 4 or 8. Consistency > perfection.

| Token | Value | Usage |
| --- | --- | --- |
| `xs` | 4px | Tight gaps, icon-text |
| `sm` | 8px | Inputs, small elements |
| `md` | 16px | Default gaps |
| `lg` | 24px | Section inner spacing |
| `xl` | 32px | Card padding, groups |
| `2xl` | 48px | Between blocks |
| `3xl` | 64px | Section padding (mobile) |
| `4xl` | 96px | Section padding (desktop) |
| `5xl` | 128px | Large hero sections (use sparingly) |

## Guidelines
- **Vertical rhythm**: Sections need breathing room (>= 64-80px desktop common)
- **Stacking**: Use consistent gap between related elements
- **Padding > margin hacks**: Prefer padding on containers
- **Mobile first**: Scale down aggressively (e.g. 64px -> 40-48px)
- **Optical alignment**: Sometimes 7px looks better than 8px, but rare
