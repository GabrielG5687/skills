# Hero Patterns

## Checklist
- [ ] **Value proposition in H1**: Answers "What do I get?"
- [ ] **Supporting subhead**: Clarifies for whom / how
- [ ] **Single primary CTA**: One button with clear action
- [ ] **Visual supports**: Image/mockup/illustration reinforces, doesn't distract
- [ ] **Works above fold**: On 375-430px width

## H1 Guidelines
- **Length**: 20-40 characters ideal for scanning
- **Focus**: Outcome > product name
- **Avoid**: "The #1 platform for...", "Revolutionary...", hype words
- **Examples**: "Turn feedback into action", "Build forms that convert"

## CTA Pairing
| Context | Suggestion |
| --- | --- |
| SaaS trial | `Start free trial` / `Get started free` |
| Waitlist | `Join waitlist` |
| Lead gen | `Get my quote` / `Book consultation` |
| Product page link | `See how it works` (only if truly secondary) |

## Common Fixes
- **Vague H1** -> Rewrite to benefit-focused
- **Two CTAs same weight** -> Make one primary, other text/link or secondary style
- **CTA below long text** -> Move higher or shorten copy
- **Hero image stealing focus** -> Reduce size or move to side on desktop
