# Color Systems for Landing Pages

## Minimal Palette
Keep it tight. You only need a few roles.

| Role | Purpose | Notes |
| --- | --- | --- |
| `background` | Page bg | Usually `#fff` or very subtle tint |
| `surface` | Cards/sections | Slightly different or same with border/shadow |
| `text-primary` | Headings/body | High contrast |
| `text-secondary` | Subheads/labels | Lower contrast but still readable |
| `accent/primary` | CTAs/links | Your only "action" color ideally |
| `border` | Dividers/inputs | Subtle |
| `success/warn` | States | Only if used in forms/UX |

## Contrast Targets
| Element | Minimum | Target |
| --- | --- | --- |
| Body text (<18px) | 4.5:1 (WCAG AA) | >= 4.8:1 |
| Large text (>=18px bold or >=24px) | 3.0:1 | >= 4.5:1 |
| Primary CTA text vs button bg | 4.5:1 | >= 4.5:1 |
| Links in body | 4.5:1 or distinguishable | Must be clear |

## Tips
- **One accent**: Don't use 3 different CTA colors
- **Avoid pure gray #999** for body text on white (often fails)
- **Neutrals work**: Slate/Gray scales are safe
- **Don't rely on color alone**: Icons/links need other cues
- **Dark mode rare** for landing pages, skip unless requested
